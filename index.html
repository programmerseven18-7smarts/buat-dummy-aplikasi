Langkah 01

Diskusi AI & Formulasi Prompt

Sebelum masuk ke v0, diskusikan fitur sistem dengan LLM untuk mematangkan konsep dan struktur.

Menyusun Fitur & Requirement

Jangan langsung menulis code. Minta AI merumuskan sistem aplikasi dummy Anda terlebih dahulu.

1
Tentukan Target User & Peran

Misal: Admin, Manajer, Operator (Tentukan hak aksesnya).

2
Tentukan Modul Utama

Tabel Master, Form Input, Dashboard Statistik, Report.

3
Buat Skenario Data Dummy

Minta AI menyiapkan JSON dummy data yang realistis untuk ditampilkan.

4 Poin Wajib dalam Prompt v0

Pastikan prompt Anda untuk v0 mengandung 4 elemen kunci berikut agar aplikasi dummy responsif & interaktif:

1. Tema Warna Spesifik

Tentukan palet warna agar desain memiliki kecocokan visual. Contoh: "Gunakan skema warna dark premium dengan aksen indigo dan violet."

2. Menu & Hak Akses (RBAC)

Sediakan switch role di UI untuk membedakan dashboard Admin, Operator, dll. secara interaktif.

Role: Admin Staff
3. Dropdown Searchable

Pastikan dropdown pilihan memiliki fitur pencarian untuk memudahkan jika data dropdown sangat panjang.

4. Tabel Responsive ke Card

Saat dibuka di HP, layout tabel horizontal harus berubah otomatis menjadi list card agar user-friendly.

Langkah 02

Alur Kerja v0.dev: Dua Pilihan Mulai

Pilih metode pembuatan project di v0 sesuai kebutuhan (Menggunakan template GitHub atau langsung generate dari nol).

PENTING: Sebelum melakukan import di v0, pastikan Repository GitHub Anda diset ke PUBLIC, bukan Private. v0 tidak dapat membaca repository private tanpa autorisasi penuh.
1
Persiapkan Repository GitHub

Pastikan boilerplate / template base code project Anda sudah di-push ke GitHub dan diset ke Public.

visibility: public
2
Create Project & Import

Buka dashboard v0.dev, klik tombol "Create Project" lalu pilih menu "Import from GitHub".

https://github.com/
3
Masukkan Prompt & Referensi Komponen

Saat menulis prompt di chat v0, wajib beri referensi template agar AI menggunakan struktur component, style, dan config yang sama dengan template Anda.

💡 Gunakan frase ini di prompt:

"...gunakan style, layouting, dan custom UI components yang ada di repository template yang di-import..."

Membuat Project Tanpa Template (Dari Nol)

Cara ini sangat cocok untuk eksplorasi cepat ide baru tanpa terikat layout project sebelumnya.

  • Desain fleksibel, sepenuhnya diatur oleh instruksi prompt.
  • Cocok untuk UI Dashboard standar/umum.
  • Menggunakan default styling system v0 (Shadcn/UI + TailwindCSS).
